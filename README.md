# 特产后备箱 techan-tetris

国庆返程玩梗小游戏：爸妈往你后备箱里塞了 **8 样特产**，后备箱只有 **6×4 格**，
载重上限 **28 斤**。轮流放置、可旋转，实在放不下就含泪舍弃——但超重会直接把后备箱压塌！

致敬每年国庆返程"后备箱被爸妈塞满"的全网玩梗，纯属娱乐。

## 玩法

- 8 样特产（全部虚构命名）：土鸡蛋 1×1、腊肉 2×2、香肠 1×3、土鸡 L 形、
  月饼盒 1×2、辣椒串 2×1、腌菜坛 L 形、红薯 T 形。每样有重量（斤）与爱意值。
- 每轮给出一样特产，输入 `行 列 旋转次数`（如 `0 2 1`）放置，旋转 0/90/180/270；
  输入 `q` 含泪舍弃（爱意 -5）。
- 8 样总重 30 斤 > 上限 28 斤，**至少要舍弃一样**，舍哪样是门道。
- 载重超 28 斤立刻"压塌"，游戏结束，喜提"超载战神"。

得分 = 装下特产的爱意值之和 − 5 × 舍弃数量。理论最高分 71（只舍弃辣椒串）。

## 运行

```bash
python3 -m techan_tetris                 # 交互模式（需要终端）
python3 -m techan_tetris --auto --games 10 --seed 42          # AI 自动演示 10 局
python3 -m techan_tetris --auto --games 1 --seed 7 --verbose  # 看单局后备箱 ASCII 图
```

纯 Python 标准库（argparse/random/sys），Python 3.10+。

## 已知局限（诚实版）

- 重量/爱意值拍脑袋设定，平衡性未经大规模仿真；理论最高分 71 只是笔算，未做最优策略搜索。
- AI 是"第一个能放就放"的贪心，不会规划，经常错过更优摆法。
- 回溯求解器只验证了"存在一组全装下的摆法"，未验证"重量 ≤28 斤且全装下"（总重 30 斤，全装下必然压塌，这是设计如此）。
- 纯文本界面，无图形/音效/存档；中文显示取决于终端编码。
